- 新增：🎨 智能修图彻底并入聊天——不再是独立整屏视图，而是技能胶囊「💬 对话 / 🎨 智能修图 / ⚔️ 多 Agent 辩论 / ⚙️ 模型与 Key」里的一员；点胶囊后消息区让位给修图面板，底部输入条与四颗胶囊原样保留，随时一键切回对话
- 新增：💄 智能修图美颜——肤色软掩码（YCbCr 椭圆 + 暖色约束）+ 双向盒式模糊磨皮，只在肤色区域替换像素；新增 beauty 滑杆（0~100，粉色轨道）与 关闭/轻度/中度/深度 四档，拖动时按 rAF 合并渲染
- 新增：🎞 滤镜预设升级为 10 个（新增「胶卷复古」「重工业感」，「电影感」重新调参）；AI 参数 JSON 字段同步扩充 hue 与 beauty，分析/按描述修图可自动给出磨皮强度

- 新增：🐳 DeepSeek 模型矩阵扩充为 6 条 —— V4.1 Flash(视觉版) / V4 Pro(旗舰) / R1(深度推理) / V3(通用对话) + OpenRouter 免费通道 deepseek/deepseek-v4.1-flash:free、deepseek/deepseek-r1:free
- 新增：🏭 按厂家视图的 DeepSeek 节点拆成三级子专区「🐳 官方旗舰与推理 / 📷 官方视觉与多模态 / 🆓 第三方免费通道」，OpenRouter 的 DeepSeek 模型并入同一节点但使用各自 Key
